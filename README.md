# Pythos Studio
`npm install && npm run dev` · `npm run build`
**Auto-discovered assets (just drop files in, reload):** `src/assets/hero-flow/` (hero streams), `src/assets/works/<slug>/` (category/project images, matched by sorted order), `src/assets/founder/cyber.webp` + `real.webp`.
**Content:** edit `src/data/categories.js` (categories, projects, map nodes, process steps) and `src/data/navigation.js`.
Placeholders render when folders are empty. Set your real email/social links in `navigation.js`.
